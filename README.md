# DEFIXAS ENGINE NEXUS

### AI Integration Platform for modern game development

DEFIXAS ENGINE NEXUS brings AI providers, development tools, workspaces, integrations, and supported game-development systems together inside one unified Windows application.

Connect your tools. Manage your workflow. Build faster.

---

## 🚀 Version

**Current Release:** `v1.0.0`  
**Platform:** Windows x64  
**Release Type:** Public Test Beta

---

## ✨ What is ENGINE NEXUS?

ENGINE NEXUS is a unified AI development platform designed to reduce the friction between AI tools, game engines, project workflows, and supporting development systems.

Instead of managing everything separately, ENGINE NEXUS gives you one central workspace for supported integrations such as:

- Codex
- Nwiro
- Unreal Engine
- AI providers
- Development workspaces
- Dependency management
- System monitoring
- Integration readiness

More integrations are planned as the platform develops.

---

## ⚡ Key Features

- Unified AI development workspace
- Codex integration
- AI Work Room
- Chat, Task, Code, and All Context modes
- Guided first-run setup
- Automatic dependency readiness checks
- Workspace support
- Persistent configuration and session state
- System statistics and telemetry
- Integration and connection status
- Windows installer and uninstall support
- Modular architecture designed for future integrations

## 🧠 AI Work Room

The AI Work Room provides a focused environment for interacting with supported AI providers.

Available context modes include:

- **Chat**
- **Task**

This allows ENGINE NEXUS to adapt the workspace to the type of development work currently being performed.
