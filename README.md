# EngineNexus
DEFIXAS ENGINE NEXUS — A unified AI development platform that connects Codex, Nwiro, Unreal Engine, and other tools into one powerful workspace for building, automating, and managing game development workflows.

DEFIXAS ENGINE NEXUS
Version 1.0.0

DEFIXAS ENGINE NEXUS is a Windows AI Integration Platform for connecting AI providers, development tools, workspaces, integrations, and supported game-development systems through one desktop application.

INSTALLATION
1. Run EngineNexus_Setup_1.0.0_Windows_x64.exe
2. Accept the licence agreement.
3. Complete the installer.
4. Launch DEFIXAS ENGINE NEXUS from the Start Menu or desktop shortcut.

SYSTEM REQUIREMENTS
- Windows 10 or Windows 11, 64-bit
- Supported development tools/integrations depend on the modules selected during setup.
- Internet access may be required for AI providers, dependency downloads, or connected online services.

SECURITY NOTE
This release is currently unsigned. Windows SmartScreen may therefore display a warning until official DEFIXAS code signing is introduced.

VERIFYING THE DOWNLOAD
SHA-256 checksums are provided in SHA256SUMS.txt.
