# Geometry-first visual fidelity sprint

User references: sculpted dragon hindleg variant sheet and complete detailed dragon in Blender 4.2.2 LTS. The quality bar is organic sculpted anatomy, not just a coarse dragon silhouette.

Requirements: complete LOD0 under 200,000 triangles; real geometry for muscles, tendons, layered scales, horns, claws and curved membranes; textures deferred. No disconnected creature components. All asset tests export real front, side and three-quarter Blender clay PNGs. Full dragon also renders head and wing closeups.

A technical pass is NOT a visual reference match. Reference status stays NOT_VISUALLY_APPROVED until actual rendered geometry is inspected side-by-side with the user's images. Tests without a supplied category-specific reference must be marked not assessable, never automatically approved.

The procedural sculpt pass is an incremental improvement, NOT a recreation of the high-detail screenshot. The source image is only one angle of an unknown mesh. A source .blend/.glb or approved image-conditioned 3D generation is the realistic route to that level. Do not upload private images or spend credits without approval.
